## 許容誤差

小さな固定数値の自動比較は**絶対誤差1e-10**以内とします。入力は小さな整数や有限小数、計算は倍精度浮動小数点で、日付差は分単位の整数です。比較後に許容誤差を広げません。件数・識別子・文字列・セル型は完全一致です。画面は丸め表示されるので、表示桁に合わせて比較し、必要ならExcel明細を確認します。OCR転記に許容誤差は設けません。原本と違う文字・小数点・限定表記は訂正してから確認します。
