# 無料β候補版の本人向け手動検証

対象：**v0.8.1-beta.1**。対象ブランチ・Commit IDと公開上の残条件は [STATUS](STATUS.md) を確認してください。自動テストとこの本人検証は別です。本番サイトの更新や公開承認を行う手順ではありません。

## 1. 起動と記録の準備

この候補版のフォルダを使用します。現在の本番サイトを開いても候補版の確認にはなりません。既存の実データに影響させないため、初回はテスト専用のブラウザプロファイル、またはプライベートウィンドウで始めてください。保存・再読込の検証は同じウィンドウを閉じる前に行います。プライベートウィンドウをすべて閉じると保存内容が失われる場合があります。

通常のExcel/CSV機能は `Launch.html` の直接起動でも利用できます。Document IntelligenceはWorker・OCRモデルを取得するため、次のローカル起動で確認します。Python 3が必要です。リポジトリのルートフォルダで実行してください。

```sh
python3 -m http.server 8770 --bind 127.0.0.1 --directory .
```

ブラウザで **http://127.0.0.1:8770/Launch.html#home** を開きます。サーバーを停止するときは、起動したターミナルで **Ctrl+C** を押します。これは本人PCの127.0.0.1に限定した起動です。外部公開トンネルは使いません。すでに8770が使用中なら空いている番号に替え、記録シートにも実際のURLを残します。

`demo-data/Manual_Test_Checklist.xlsx` を `local-test-results/` にコピーしてください。Statusはすべて **Not Tested** から始まります。`Version or Commit`に実際に開いた候補版のCommit IDを記録します。時間・評価・実際の結果は本人が測って記入します。入力データと手動結果を自動コミットしないでください。

ここでは詳細手順を先に読まず、仕事が完了するかを試してください。迷った時点と回避策を記録し、その後にTest IDの詳細へ進みます。

Time to Resultはファイル準備・設定・確認・修正を含め、結果を解釈できた時点まで。Time to Exportは出力後のファイルを開き、内容確認や手直しを終えるまでの総時間です。Excelと比較する場合も同じ入力から同じ出力が完成するまでを測ります。操作の迷い、設定再利用の手間、やり直し回数も記録します。

## 3. 詳細テスト共通ルール

以下の全Test IDはv0.8.1-beta.1と、記録シートに書いたCommit IDが対象です。ファイルパスはすべて `demo-data/` からの相対パスです。Aは業務体験、Bは正解確認で、各D番号の機械可読な正解は `expected/Dxx.json` にあります。式・許容誤差は `expected/definitions.json` と `expected/README.md` を参照します。

**初期状態 S0**：テスト用ウィンドウでホームを開き、前のテストの出力・未保存入力を退避済み。前のファイルが残るツールは再読込してから新しいファイルを選びます。Presetは新規の `BETA-TEST-...` 名で作り、既存名を上書きしません。

**初期状態 S1**：同じグループの直前テストが開いている状態。表に指定したファイル・設定になっていることを確認します。

**成功条件**：各テストの期待値・警告・出力がすべて一致し、処理が完了すること。ダウンロードだけでは合格にせず、出力をExcelやPDFビューアで開き、件数・数値・識別子・日本語・図・改ページを確認します。分からない条件はBlockedとし、推測でPassにしません。

**失敗時 F**：Test ID、Commit、ブラウザ名・版、OS、入力ファイル名、選択シート/見出し/列/期間、実際の表示、期待との差、再現手順、迷った箇所を記録します。画面画像はデモだけに限定します。外部のご意見フォームへ実データ・製品名・ロット・検査値・例外全文を貼りません。

**安全なリセット R0**：出力や変更を必要に応じて退避してから、このテストタブを再読込します。実データを含む別タブは触りません。保存済みPresetを消す必要はありません。「このツールの保存設定を消去」やブラウザ全体のサイトデータ消去を試験のリセットとして使いません。

**安全なリセット R1**：定例品質・バッチは「作業をファイルに保存」で `.mtb` を退避してからR0。RCIは「RCIを保存」で `.rci` を退避してからR0。OCRは保存が必要なら「データをバックアップ」で `.mtbd` を退避してからR0。復元時の置換確認は読み、デモだけの状態と確認できた場合に続行します。
