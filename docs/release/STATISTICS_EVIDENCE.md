## 採用する計算定義

### 工程能力と管理図

- 平均は有効数値の算術平均。標準偏差は標本標準偏差 `s = sqrt(sum((x - mean)^2)/(n - 1))`。母標準偏差の分母 `n` は使いません。
- Individualsでは隣接する有効値同士の絶対差をMRとし、`σwithin = MR平均 / 1.128`。欠損位置を飛ばしてMRを結びません。
- Individualsの管理限界は `mean ± 3σwithin`。MRは `LCL = 0`、`UCL = (1 + 3 × 0.8525 / 1.128) × MR平均`。内部では導出したD4を再丸めしないため、表にある丸め値3.267との比較には違いがあります。[NIST Individuals](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc322.htm)
- Xbar-Rは固定サイズ2〜10の連続群を使います。完全な有効群を2群以上必要とし、欠測を含む群や末尾の不完全群は群全体を除外します。`σwithin = R平均/d2`、Xbar限界は `grand mean ± 3σwithin/sqrt(群サイズ)`、R限界は `D3 × R平均` と `D4 × R平均`。合理的な群分けであることを利用者が確認する必要があります。[NIST Xbar-R](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc311.htm)
- Cpは規格幅を `6σwithin` で割り、Cpkは上下の規格までの距離を `3σwithin` で割った小さい方です。Pp/Ppkは同じ形式で分母に全有効値の標本標準偏差 `s` を使います。これは今回変更していません。[Minitab within能力の定義](https://support.minitab.com/en-us/minitab/help-and-how-to/quality-and-process-improvement/capability-analysis/how-to/capability-sixpack/normal-capability-sixpack/interpret-the-results/all-statistics-and-graphs/within-capability/)、[Minitab Cpk/Ppkの区別](https://blog.minitab.com/en/blog/process-capability-statistics-cpk-vs-ppk)
- 片側規格ではCp/Ppを出さず、指定側だけのCpk/Ppkを出します。規格がないときの規格外率は未評価です。規格上・下限に等しい値は規格内、規格外率の分母は実際に解析へ採用した有効測定数です。Xbar-Rで除外した群は分母にも含めません。
- 分散ゼロ、MRが作れない場合、少なすぎる群数などの計算不能は値を捏造せず空欄または明示エラーにします。定例品質は設定した最低件数（初期値5）未満の能力指数を表示しません。単一工程能力では数学的に計算できる少数値を参考値として表示するため、5件例は工程能力評価に十分な標本数を意味しません。
- 規格限界は入力した製品要求で、管理限界は今回の測定ばらつきから算出した統計値です。能力指数だけで製品の合否や改善の因果を判定しません。[NIST 工程能力](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc16.htm)
- Nelsonは既存の1〜8ルールを維持。境界ではRule 1/5/6/8は厳密な超過、Rule 7は±1σ境界を含みます。Rule 8は8点すべてが±1σの外側であれば片側だけでも成立します。欠測・元indexの断絶で連続をリセットします。MR/Rは管理限界超過だけを判定し、I/Xbar用の全ルールを適用しません。[Minitab 特殊原因検定](https://support.minitab.com/en-us/minitab/help-and-how-to/quality-and-process-improvement/control-charts/supporting-topics/basics/using-tests-for-special-causes/)

### 期間と順序

- 管理図は既存どおりロットの自然順を優先し、同じロットの順序は安定して維持します。日付は点の補足・表示範囲に使います。ロット順が実際の採取順を表さない場合には、利用者が入力順の意味を確認する必要があります。
- 単一工程能力のグラフ上の期間バー・日付範囲は表示だけを絞ります。全データで求めた能力指数・管理限界を再計算しません。
- 定例品質の当期間・前期間は対象行を絞ってから、それぞれ平均・ばらつき・管理限界を再計算します。前期間の限界を当期間へ固定適用する機能ではありません。両期間の条件が異なる場合は比較しません。
- 日時付きの明示タイムゾーンはUTCの瞬間に変換します。タイムゾーンなしの文字列・Excelシリアルは元の壁時計時刻として扱い、混在は分離または停止します。曖昧な `01/02/2026` は日付として採用しません。表示言語で解析を変えません。

### 時間・分位数・パレート

- 分位数はR7（0始まりの位置 `(n - 1) × p` で線形補間）で、ExcelのPERCENTILE.INCと同じ定義です。最低件数未満は分位数を表示しません。[Microsoft PERCENTILE.INC](https://support.microsoft.com/en-us/excel/functions/percentile-inc-function)
- サイクルタイムは同じ設備上の実際の次バッチのStart−今回Start、加工時間は今回End−Start、空き時間は次Start−今回Endです。別製品を飛ばしません。最終行は次のStartがないため加工時間だけです。加工時間の有効な6日なども含めます。終了が開始より前なら翌日へ補正しません。
- Cycle TimeにはIQR除外のUIはありません。全有効値の分位数を出します。除外前後の体験は既存のバッチ工程分析で行います。
- バッチの工程時間合計は各時間の和、記録時間は区間の和集合、実経過は最初の開始から最後の終了までです。空白は実経過−和集合として計算し、原因を設備停止と決めつけません。無効な観測工程があるバッチの全体経過・空白は出しません。「完全」とは記録された行が有効という意味で、未記録工程がないことの保証ではありません。
- バッチのIQR除外はQ1−1.5×IQRより小さいか、Q3＋1.5×IQRより大きい値を統計上の候補とします。初期値では除外せず、除外する場合も全データ統計を残します。物理的な時間線・ロス・パレートから長い工程を消しません。
- パレートは同じカテゴリを合算して降順、割合と累積割合の分母は有効な非負数量の総和です。空カテゴリ、数値でない数量、負数は除外対象です。全件0は分母が0で割合・累積割合が未定義のため、図・単体パレート出力を停止して理由を表示します。バッチレポートでは数量0を保持し、割合・累積割合は空欄にします。
