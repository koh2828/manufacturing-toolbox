# OCR Accuracy Test Report

測定日: 2026-10-14（Asia/Tokyo）。本書は実際のブラウザ内PDF.js・Tesseract.js出力と、別に保持した正解JSONを照合した結果です。OCR結果を模擬した単体テストの点数は含めていません。

## 評価範囲と結論

架空の3サプライヤー、各2製品、16成績書・20ページ・93検査行を使用しました。主要コーパスは18ページが画像スキャン、2ページがテキストPDFです。同内容の全20ページ画像PDFも実行しました。可変行数、4件の複数ページ成績書、同じサプライヤーの連続別ロット、英語・日本語、欠損欄、斜めスキャン、極端な低コントラスト、一部を隠したセルを含みます。

既定設定で、混在PDFの検査値原文は **76/93 (81.72%)**、項目と値の厳密な組の一致は **60/93 (64.52%)** でした。日本語OCRで挿入された空白だけを除いた補助指標は **72/93 (77.42%)** です。空白以外の誤読や取り違えは補助指標でも誤りに数えています。自動抽出後も原本との照合・訂正が必要です。

このコーパスはテンプレートや処理設定の開発にも使っています。未知の帳票、実企業の帳票、独立した検証用データに対する精度ではなく、製品全般の精度保証でもありません。比較設定の採用はこの開発コーパスでの改善に基づきます。

## 測定方法

- 既定設定: `eng+jpn`、`block` (Tesseract PSM 6)、原画像、PDF描画scale2。未知の帳票に万能な設定とは位置付けません。
- 生成元の正解JSONはページ・文書境界・各フィールド・検査行・原文値・概略位置を独立に保持しています。
- 文字列の完全一致は、先頭末尾の空白と連続空白の折りたたみだけを行います。大小文字、数字、句読点、Unicode表記、別名を都合よく修正しません。
- 行は同一原本ページ内の縦位置と順序で対応付けます。認識された項目名や値を使って有利な組み合わせを探しません。対応しない行と余分な行は別に数えます。
- 補助指標だけは項目名と値の空白をすべて除去します。編集距離や類似名判定は行わず、アプリの保存値も変更しません。
- 読みにくいセル、抽出漏れ、表未検出を93行の分母から除外しません。Lotが原本から欠損している1ページだけは、Lot文字列一致の分母に含めません。
- 一度も人が訂正・確認していない初回抽出を評価しています。テンプレートの訂正別名を後付けした点数ではありません。

## 主な誤認識と原因

- 日本語の単語分割: `揮発分`が`揮発 分`、製品名`青葉溶液A`が`青葉 溶液 A`となる例。原文を維持し、確認後に明示的な項目別名・製品別名を登録できます。
- 日本語文字の誤読: `粘度`が`HE`などになる例。日本語優先のモデル順でも一律には改善しませんでした。
- 数字と記号: `100 ± 5`の記号が失われる、`95–110`が`95-110`になる例。元の記号を推測して補正していません。
- 傾いたページ6・19では、表見出しや行位置の解釈が失敗しました。読み取れなかった行を別の検査項目へ勝手に割り当てません。
- 一部を隠したページ16のセルや極端に薄いページ11では、原本の欠落・画像品質に起因する制約があります。再スキャンや原票確認が必要になる場合があります。
- 規格外の112.5は意図した真の測定値です。規格外を理由にOCR誤りと決めつけず、規格外表示と読取確認を区別します。

## 設定・前処理の比較

同じTesseract.jsで言語（英日、日本語、日英）、自動レイアウトとブロックレイアウト、解像度、コントラスト、二値化、傾き補正・ノイズ処理を実行しました。異なるOCRエンジンでの認識精度比較は実施していません。Paddle/ONNX系について、未実装の比較結果を実測として扱っていません。

初期の英日・自動レイアウトでは66行、検査値58/93、項目と値58/93、対象セルの不一致210でした。既定のブロックレイアウトに変えると84行、検査値76/93、項目と値60/93、不一致91セルに改善しました。このためブロックを初期値とし、変更できるようにしています。

日本語優先・ブロックの全20ページ比較は検査値74/93、厳密な組58/93で、英日・ブロックを上回りませんでした。コントラスト調整や二値化は薄い文字を消したり誤認識を増やす場合があり、全ファイルへ自動適用していません。画像の品質に応じて元画像と再処理結果を確認する設計です。

### 明示的な再処理後の結果（初回抽出とは別評価）

原本を見てページ6に+2度、ページ19に-1.5度の補正（画面上の正は時計回り）を選び、ページ19だけノイズ処理も選択しました。これは真の傾きを知った検証者による選択で、自動傾き推定の成果ではありません。補正画像の座標で表を組み立て、原本表示には元の座標を使うよう実装を修正し、関連単体テストを追加しました。

この操作で欠落していた10行を抽出でき、欠落0行・余分1行となりました。検査値は84/93 (90.32%)、厳密な項目と値の組64/93 (68.82%)、空白だけを除いた組80/93 (86.02%)でした。文書は17件（正解16件）、境界判定18/19 (94.74%)、Lot18/19 (94.74%)です。相違する対象セルは57に減りました。17文書すべて未確認のままです。

追加処理時間はページ6が0.915秒、ページ19が1.113秒でした。画像確認・角度を選ぶ操作時間は含みません。`1,234.5`が`1.234.5`となる誤読は残り、値を推測して直さず文字列と警告として保持します。主表の初回精度へ、この操作後の高い数値を混ぜていません。
